# Zovo Headers

Set or remove HTTP request and response headers on the sites you choose. Standing per-site rules, applied by Chrome.

Free and open source. If it saves you time, you can support the work on [GitHub Sponsors](https://github.com/sponsors/theluckystrike), [PayPal](https://paypal.me/najzzz) or [Buy Me a Coffee](https://buymeacoffee.com/michaellip).

## Install

- From the Chrome Web Store: [Zovo Headers](https://chromewebstore.google.com/detail/mimoffdfbiekkooiglhhgfinlafikihl). Version 1.0.1.
- From this repository: open `chrome://extensions`, turn on Developer mode, click Load unpacked, and select this folder. No build step is needed.

## Permissions

`declarativeNetRequest`, `storage` plus host access for `https://zgubxqomnbmxgbdhvwja.supabase.co/*`.

## Pro features

The Chrome Web Store version asks for a Zovo membership key for some features. The key check runs in your browser, and its code is in this repository. The MIT license lets you use and change all of this code. If the extension helps you, please support the work with one of the links below.

## About this code

This repository holds the files of the published Chrome Web Store package, version 1.0.1. The code is a bundled build. The original source files are not available yet. Load unpacked still works.
